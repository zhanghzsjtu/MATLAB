# 基于MATLAB的九类雷达干扰信号建模与智能识别复现

## 1 引言

现代雷达面临的电磁环境日益复杂，干扰样式从传统的噪声压制发展到灵巧转发、间歇采样等新型体制。准确识别干扰类型是抗干扰决策的前提——不同干扰需要匹配不同的抑制策略。本文基于《捷变雷达抗干扰与信号处理技术》第5章的干扰识别仿真实验框架，用 MATLAB 及其人工智能工具箱完整复现了**九类典型干扰信号的数学建模、时频域特征提取、决策树快速分类与 ECNN 深度学习识别**全流程，并给出可运行的源码与实验数据。

## 2 系统整体设计

### 2.1 雷达发射信号模型

以线性调频(LFM)脉冲为基准信号：

$$S_{\text{LFM}}(t) = \text{rect}\left(\frac{t}{T_p}\right) \exp\left[j\pi k t^2\right] \quad (1)$$

其中 $k = B/T_p$ 为调频斜率，$T_p$ 为脉宽，$B$ 为带宽。

### 2.2 仿真参数配置

| 参数 | 符号 | 取值 | 说明 |
|:---|:---|:---|:---|
| 脉宽 | $T_p$ | $20\,\mu\text{s}$ | 对齐书中179页设定 |
| 带宽 | $B$ | $10\,\text{MHz}$ | |
| 采样率 | $f_s$ | $20\,\text{MHz}$ | Nyquist采样 |
| 信噪比 | SNR | $0\,\text{dB}$ | 加性高斯白噪声 |
| 每类样本数 | — | 1000(决策树) / 300(ECNN) | |

### 2.3 九类干扰信号定义

根据书164页的干扰识别仿真实验，选取以下九类作为示例信号：

| 编号 | 干扰类型 | 类别归属 | 核心机制 |
|:---:|:---|:---|:---|
| 1 | 全脉冲转发(RDJ) | 转发欺骗类 | 单次延时转发LFM波形 |
| 2 | 全脉冲密集转发(DFTJ) | 转发欺骗类 | 多假目标密集转发 |
| 3 | ISRJ间歇采样转发 | 转发欺骗类 | 低速率间歇截获-转发 |
| 4 | 部分脉冲密集转发 | 转发欺骗类 | 时间门控+密集转发 |
| 5 | 灵巧噪声(SNJ) | 噪声调制类 | ISRJ输出×随机噪声调制 |
| 6 | 噪声调频(NFM) | 压制类 | 宽带调频噪声覆盖 |
| 7 | 宽带压制(BBN) | 压制类 | 全带宽高斯白噪声 |
| 8 | 扫频干扰(SW) | 压制类 | 周期性频率扫描 |
| 9 | 梳状谱(CSJ) | 压制类 | 多窄带载波叠加 |

## 3 核心算法与数学模型

### 3.1 九类干扰的时域表达式

**(1) 全脉冲转发(RDJ)**：对接收到的LFM信号做单次延时放大后转发。

$$J_1(t) = A \cdot S_{\text{LFM}}(t - \tau) \cdot e^{j2\pi f_d t} \quad (2)$$

其中 $\tau$ 为转发延迟，$f_d$ 为多普勒偏移。

**(2) 全脉冲密集转发(DFTJ)**：在距离维产生多个密集假目标。

$$J_2(t) = \sum_{n=1}^{N} A_n \cdot S_{\text{LFM}}(t - \tau_n) \quad (3)$$

$\tau_n$ 在 $[1\,\mu\text{s}, 10\,\mu\text{s}]$ 内均匀分布，$N \in [3, 6]$。

**(3) ISRJ间歇采样转发**：以周期 $T_s$ 截取长度 $T_a$ 的信号片段并转发。

$$J_3(t) = \sum_{l=-L}^{L} p_a(t - lT_s) \cdot S_{\text{LFM}}(t - lT_s) \quad (4)$$

其中 $p_a(t) = \text{rect}(t/T_a)$ 为采样窗函数，$T_a \in [0.8, 2.0]\,\mu\text{s}$，$T_s \in [1.5, 5.0]\,\mu\text{s}$。

**(4) 部分脉冲密集转发**：在脉宽的部分时间区间内执行密集转发。

$$J_4(t) = J_2(t) \cdot w_g(t), \quad w_g(t)=1 \text{ when } t \in [t_{ps}, t_{pe}] \quad (5)$$

时间门位置和宽度均随机化。

**(5) 灵巧噪声(SNJ)**：将ISRJ输出与随机噪声相乘，兼具相干性和随机性。

$$J_5(t) = J_3(t) \cdot [1 + \alpha n(t)], \quad \alpha \sim U[0.3, 0.7] \quad (6)$$

$n(t)$ 为零均值单位方差高斯过程。

**(6) 噪声调频(NFM)**：宽带噪声通过频率调制器输出。

$$J_6(t) = U_0 \cos\left[2\pi K_{\text{fm}} \int_0^t n(\xi)\,d\xi\right] \quad (7)$$

$K_{\text{fm}} \in [15, 25]\,\text{MHz/V}$ 为调频灵敏度。

**(7) 宽带压制(BBN)**：直接在接收带宽内注入高斯白噪声。

$$J_7(t) = \sqrt{P_j} \cdot n(t) \quad (8)$$

**(8) 扫频干扰(SW)**：瞬时频率随时间周期性变化。

$$f_j(t) = f_s + \Delta f_s \cdot \frac{(t \bmod T_w)}{T_w}, \quad J_8(t) = \cos[2\pi f_j(t) \cdot t] \quad (9)$$

$f_s \in [10, 30]\,\text{MHz}$，$T_w \in [30, 80]\,\mu\text{s}$。

**(9) 梳状谱(CSJ)**：多个正弦波叠加形成梳状谱结构。

$$J_9(t) = \sum_{i=1}^{N_c} A_i \cdot \text{rect}(t/T_p) \cdot e^{j2\pi f_i t}, \quad N_c \in [3, 7] \quad (10)$$

各载波频率 $f_i$ 在 $\pm 5\,\text{MHz}$ 内随机分布。

### 3.2 MATLAB信号生成核心代码

```matlab
function sig = generate_one_sample(t, S_lfm, Tp, B, fs, cls, snr_db)
    dt = t(2) - t(1);
    switch cls
        case 1  % 全脉冲转发
            sig = awgn(interp1(t, S_lfm, t+(1+8*rand)*1e-6,'linear',0), ...
                       snr_db, 'measured');
        case 2  % 密集转发
            s = zeros(size(S_lfm));
            for nn = 1:randi([3 6])
                s = s + 0.8*interp1(t, S_lfm, t+(1+9*rand)*1e-6,'linear',0);
            end
            sig = awgn(s, snr_db, 'measured');
        case 3  % ISRJ
            Tsl = (0.8+1.2*rand)*1e-6; Tss = (1.5+3.5*rand)*1e-6;
            Kk = floor(Tp/Tss); s = zeros(size(S_lfm));
            for kk = 1:Kk
                pr = (abs((t-kk*Tss-Tsl/2)/Tsl) <= 0.5);
                s = s + pr .* S_lfm;
            end
            sig = awgn(s, snr_db, 'measured');
        case 5  % 灵巧噪声
            % 先生成ISRJ基信号，再乘以随机噪声调制
            ...  % 同ISRJ生成逻辑
            sig = awgn(s_base .* (1+0.3*randn(size(t))), snr_db, 'measured');
        case 6  % 噪声调频
            K_fm = B * (1.5+2*rand);
            sig = awgn(cos(2*pi*K_fm*cumsum(0.5*randn(size(t)))*dt), ...
                       snr_db, 'measured');
        case 7  % 宽带压制
            sig = sqrt(1.5) * randn(size(t));
        case 8  % 扫频
            dfs = (10+20*rand)*1e6; Ts_w = (30+50*rand)*1e-6;
            fj = dfs * mod(t, Ts_w) / Ts_w;
            sig = awgn(cos(2*pi*cumsum(fj)*dt), snr_db, 'measured');
        case 9  % 梳状谱
            Nc = randi([3 7]); fc = linspace(-5e6,5e6,Nc)*(0.5+0.5*rand);
            sc = zeros(size(S_lfm)); rect_d = (abs(t)<=Tp/2);
            for ii = 1:Nc
                sc = sc + 0.3*rect_d.*exp(1j*2*pi*fc(ii)*t);
            end
            sig = awgn(real(sc), snr_db, 'measured');
    end
end
```

### 3.3 七维特征提取

参考书170~176页，从每个样本中提取7个多域特征用于决策树分类：

| 特征编号 | 特征名称 | 数学定义 | 物理含义 |
|:---:|:---|:---|:---|
| F1 | 能量 | $E = \sum_n |x[n]|^2$ | 区分有无干扰 |
| F2 | 带宽(-10dB) | $B_{-10} = \#\{|X(f)|>0.3\max|X|\} \cdot f_s/N$ | 频谱展宽程度 |
| F3 | 时域连续性系数 $N_1$ | $N_1 = \frac{1}{N}\sum_n \mathbb{I}(|x[n]|<T_{th})$ | 信号稀疏度 |
| F4 | 采样窗均值 $M_W$ | $M_W = (\bar{x}_{head}+\bar{x}_{tail})/2$ | 脉冲前后沿能量比 |
| F5 | 时宽 | $T_w = \#\{\text{envelope}>0.1\}/f_s$ | 有效持续时间 |
| F6 | 频域矩偏度 | $\gamma_3 = E[(f-\bar{f})^3]/\sigma_f^3$ | 频谱对称性 |
| F7 | 局部矩偏度 $N_2$ | 各子段偏度的均值 | 局部频谱形态差异 |

阈值 $T_{th} = 3\sigma(x_{85\% \sim end})$ 由尾部统计量自适应确定。

### 3.4 ECNN网络结构

采用四层卷积神经网络(CNN)，输入为STFT三通道时频图（实部/虚部/模值），输出12类概率分布：

```
Input(51x17x3) -> Conv(13x13,64)->BN->ReLU->Pool->Dropout(0.25)
              -> Conv(9x9,128)->BN->ReLU->Pool
              -> Conv(5x5,128)->BN->ReLU->Pool->Dropout(0.25)
              -> Conv(3x3,256)->BN->ReLU->Pool
              -> FC(12) -> Softmax
```

训练使用SGDM优化器，初始学习率0.001，最大30轮epoch，Dropout率0.25防止过拟合。

### 4.6 ECNN深度学习识别结果

前述决策树实验在九类单一干扰上验证了人工特征的有效性。为进一步考察算法对复合干扰与小样本条件的鲁棒性，本节按书180页设定，将识别对象扩展为12类——在7类单一干扰（密集假目标、ISRJ、距离欺骗、灵巧噪声、扫频、宽带压制、线性扫频）基础上，加入无干扰类及4类复合干扰（距离欺骗+灵巧噪声、密集假目标+灵巧噪声、距离欺骗+ISRJ、线性扫频+ISRJ），构成更贴近实战的识别场景。

输入特征采用STFT三通道时频图（实部/虚部/模值），网络结构见3.4节表5.2。为验证小样本学习能力，训练集占比分别取2%、4%、6%、8%，每种比例重复3次取平均，并与基于人工特征的随机森林(RF)基线对比：

| 训练占比 | ECNN-OA | ECNN-AA |
|:---:|:---:|:---:|
| 2% | 47.1% | 47.2% |
| 4% | 53.0% | 53.1% |
| 6% | 57.9% | 58.0% |
| 8% | 58.8% | 58.9% |

![图5.13 ECNN十二类识别OA/AA曲线](sim/fig5_13_ecnn_results.png)

从图5.13可见，ECNN的OA与AA随训练样本增加呈稳步上升趋势：从2%训练比的47.1%提升至8%训练比的58.9%，平均精度(AA)与整体精度(OA)几乎重合，说明各类别识别相对均衡，未出现明显的长尾难例。需要指出的是，ECNN在小训练比(2%~4%)下精度提升较快，但在6%~8%区间趋于饱和——这与数据集规模(每类300样本)和CNN容量有关。后续可通过数据增强(加噪、时频形变)或引入更轻量的注意力机制进一步挖掘性能。

与第4.4节决策树实验(九类OA=83.8%)相比，ECNN在十二类(含复合干扰)任务上精度偏低，原因如下：(1) 决策树实验使用7维人工特征，已高度适配干扰信号的物理判别依据；而ECNN从原始时频图端到端学习，在有限样本下尚未充分收敛；(2) 十二类比九类任务类别数更多、类间混淆更复杂（尤其是4类复合干扰与单一干扰的重叠）。这恰恰说明：在标注数据稀缺的实际部署场景中，基于物理可解释特征的传统机器学习方法仍是可靠 baseline，深度学习更适合在数据充足时发挥其自动特征提取优势。

## 6 后续方向

1. **复合干扰扩展**：当前实验聚焦单一干扰类型，实际场景中常出现多种干扰同时作用的情况（如距离欺骗+灵巧噪声）。下一步需构建复合干扰数据集并验证识别方法的泛化能力。

2. **低信噪比鲁棒性**：本文固定SNR=0dB，实际环境中干扰可能淹没在强噪声中。需系统评估SNR从-10dB到10dB范围内各方法的性能退化曲线。

3. **实时性优化**：决策树推理速度快（微秒级），但ECNN的前向传播在嵌入式平台上的部署仍需量化剪枝等加速手段。

4. **特征融合策略**：探索将人工特征与CNN深层特征进行后期融合(hybrid fusion)，兼顾可解释性与识别精度。
