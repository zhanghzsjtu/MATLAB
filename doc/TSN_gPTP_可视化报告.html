1. 系统架构与数据流

本工程是一个纯 FPGA 逻辑实现：所有模块（PHC / HTSU / TC / Pdelay / BMCA / Servo / MAC 胶合）均为可综合 Verilog，在单芯片内完成 gPTP 时间同步；验证侧采用 iverilog 分层 testbench 作为仿真兜底。单端口由 gptp_top 集成，多端口由 gptp_switch 用 generate 例化 N 份并共享一个 PHC，输出的 GM 时间可供给片上 802.1Qbv TAS 调度单元消费。

图1 单端口数据流：MAC 进 → 时间戳/透明钟/Pdelay/BMCA/Servo → PHC → MAC 出
图2 多端口交换机：N 端口共享 PHC，每端口独立 top+bmca+servo，输出 GM 时间供 TAS
关键数据流：RX 帧经 mac_glue 识别 0x88F7 → HTSU 在 SOF 硬打戳 (t2/t3) → TC 累加 residence 到 correctionField → Pdelay 测 P2P 链路不对称 → BMCA 选 GM → Servo 用 Sync offset 闭环调 PHC（adjtime/adjfine）→ 统一时间面经 TX 出帧。

2. 各模块三段式状态机总览

全部时序模块严格采用用户 Verilog 铁律：状态寄存器块仅更新 state_c；组合块用 case 计算 state_n（default=P_ST_IDLE）；输出块单信号 if-else。状态常量以 P_ST_ 前缀 + 独热编码，跳转条件用独立 p_st_<src>2p_st_<dst>_start wire 声明。

4. 同步前 vs 同步后对比

未同步时各端口独立晶振导致频率/相位发散，跨跳抖动逐跳累积；经 Servo 闭环（adjtime 消除稳态、adjfine 消除频偏）后，全网对齐到 GM 时间面，残余仅剩链路不对称（由 Pdelay 测得，约数十 ns）。

7. 创新点 / 功能点

P2P 强制测延迟one/two-step 双模 TC 32-bit DDS 分数时钟BMCA Passive 最优下一跳 三段式 FSM 统一共享 PHC + servo 仲裁 真实 TX 转发(非 RX 复用)CDC 两级同步预留 由底向上分层验证Verilog 铁律合规

相对 OpenTSN 的三个实质差异（P2P 算法、sub-ns 分数分辨率、one-step TC）是守"50ns 同步"指标的关键；servo 仲裁 + 真实 TX 转发是交换机级可扩展性的落点。

9. 验证结论

回归结果：PASS=9 FAIL=0（iverilog 12，-g2012，一次跑齐 9 个分层 tb）。
规范合规：10 个可综合模块全部满足 Verilog 编码规范（端口对齐 / 分组注释 / r_·w_·ro_ 前缀 / 三段式 FSM / P_ST_ 独热 / 独立跳转条件 wire / i_clk-i_rst 异步复位 'd0 / 单信号 always / inst 组括号对齐 / 位宽基数常数）。
待办闭合：4 个待办（switch 真实 TX 转发、servo 仲裁、CDC 两级同步、顶层 HTSU 时间戳引出）+ 5 项后续建议（bmca Passive 测试、TC 双模、switch residence、servo 仲裁验证、MAC CF 字节改写）均已实现并有 tb 覆盖。
